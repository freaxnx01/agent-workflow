# Optional `ANTHROPIC_API_KEY` for the Claude implement step — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A consumer repo that sets an `ANTHROPIC_API_KEY` secret has its Claude implement runs billed to the API credit instead of the Max subscription; without the secret nothing changes.

**Architecture:** One new optional `workflow_call` secret on `agent-implement.yml` and its shim. The "Run Claude Code" step passes `anthropic_api_key` from it and passes the OAuth token only when the key is empty. Review and self-fix are untouched and a structural test keeps the key out of them. The onboarding stub and this repo's own `agent.yml` forward the secret.

**Tech Stack:** GitHub Actions YAML, Bash 5, Python 3 + PyYAML (structural tests), `actionlint`, `shellcheck`.

**Spec:** `docs/superpowers/specs/2026-11-28-anthropic-api-key-implement-design.md`

## Global Constraints

- Secret name exactly `ANTHROPIC_API_KEY`, `required: false`, in both `agent-implement.yml` and `claude-implement.yml`.
- `CLAUDE_CODE_OAUTH_TOKEN` stays `required: true`.
- Only the step `Run Claude Code` in job `implement` may reference `secrets.ANTHROPIC_API_KEY`.
- Exact expressions in that step: `anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}` and `claude_code_oauth_token: ${{ secrets.ANTHROPIC_API_KEY == '' && secrets.CLAUDE_CODE_OAUTH_TOKEN || '' }}`.
- Do not change the pinned action SHA (`anthropics/claude-code-base-action@b95ab0675f9b2696ae6c826c15b7a12e1a4a7071`).
- Bash scripts start with `set -euo pipefail` and `IFS=$'\n\t'`; quote every expansion.
- Tests run offline; `bash tests/run-all.sh` discovers any new `tests/run-*-tests.sh` automatically.
- `CHANGELOG.md` is generated by git-cliff at release time from Conventional Commits — do **not** edit it by hand; the `feat(implement): …` commit is the changelog entry.
- Commit messages: Conventional Commits, `Refs #540` in the body.

## Review Focus

1. **Consumer forwards a secret the called ref does not declare.** A stub pinned to a `@v2` tag cut *before* this change, or onboarded from a local `main` ahead of the tag, passes `ANTHROPIC_API_KEY` to a reusable workflow that does not declare it; GitHub can reject that call. Expected: docs state that the stub line requires the release containing #540, and the reviewer checks that the next release tag is cut before onboarding relies on it. (Not testable offline; documented in Task 3.)
2. **Self-fix with `FIX_AGENT=claude`.** A self-fix pass after an API-billed implement run must still run on the subscription. Expected: no self-fix or review step receives the key. Pinned by assertion 4 in Task 1 (mutation `leak-selffix`).
3. **Key set at job level instead of step level.** A later edit that moves `ANTHROPIC_API_KEY` into a job's `env:` would leak it into every step, review included. Expected: the structural test flags any reference outside the one step, including job-level keys. Pinned in Task 1 (mutation `leak-job-env`).
4. **Both credentials reach the action.** An unconditional `claude_code_oauth_token` would make billing depend on the CLI's precedence rule. Expected: the OAuth expression is conditional on the key being empty. Pinned in Task 1 (mutation `unconditional-oauth`).
5. **Invalid or exhausted key.** A wrong or empty-credit key fails the run, probably classified `bug` (#521 makes credit classification ignore message text). Expected: docs tell the operator how to spot and undo it (remove the secret). Documented in Task 3; detection is a follow-up issue.

Create `tests/run-api-key-billing-tests.sh` (mode `0755`):

```bash
#!/usr/bin/env bash
#
# run-api-key-billing-tests.sh — structural guard for #540: the optional
# ANTHROPIC_API_KEY bills only the Claude implement step to the API credit.
#
#   1. agent-implement.yml declares the secret, required: false;
#   2. the claude-implement.yml shim declares it, required: false;
#   3. "Run Claude Code" passes anthropic_api_key from it and passes the OAuth
#      token only when the key is empty — exactly one credential reaches the CLI;
#   4. nothing else (no review, no self-fix, no job-level env) references it —
#      the CLI prefers ANTHROPIC_API_KEY whenever it is in its environment, so a
#      leak would silently move the review onto the API credit.
#
# Every assertion is also driven against a deliberately broken copy (the
# mutations below): a guard that no longer looks at anything must fail here,
# not pass silently.
#
# Usage: tests/run-api-key-billing-tests.sh
# Exit codes: 0 all pass; 1 at least one assertion failed.
set -euo pipefail
IFS=$'\n\t'

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
WF="$ROOT/.github/workflows/agent-implement.yml"
SHIM="$ROOT/.github/workflows/claude-implement.yml"
T="$(mktemp -d)"
trap 'rm -rf "$T"' EXIT

PASS=0; FAIL=0; FAIL_NAMES=()
pass() { PASS=$((PASS + 1)); printf '  ✓ %s\n' "$1"; }
fail() { FAIL=$((FAIL + 1)); FAIL_NAMES+=("$1"); printf '  ✗ %s\n' "$1"; [[ $# -gt 1 ]] && printf '%s\n' "$2" | sed 's/^/      /'; return 0; }

# check_workflows <agent-implement.yml> <claude-implement.yml> — one problem per line.
check_workflows() {
  python3 - "$1" "$2" <<'PY'
import sys, yaml
wf_path, shim_path = sys.argv[1], sys.argv[2]
KEY_REF = "secrets.ANTHROPIC_API_KEY"
WANT_KEY = "${{ secrets.ANTHROPIC_API_KEY }}"
WANT_OAUTH = "${{ secrets.ANTHROPIC_API_KEY == '' && secrets.CLAUDE_CODE_OAUTH_TOKEN || '' }}"
problems = []

def load(path):
    return yaml.safe_load(open(path))

def call_secrets(doc):
    on = doc.get("on", doc.get(True)) or {}   # PyYAML reads the key `on` as True
    return (on.get("workflow_call") or {}).get("secrets") or {}

wf, shim = load(wf_path), load(shim_path)
for label, doc in (("agent-implement.yml", wf), ("claude-implement.yml", shim)):
    decl = call_secrets(doc).get("ANTHROPIC_API_KEY")
    if decl is None:
        problems.append(f"{label}: does not declare secret ANTHROPIC_API_KEY")
    elif decl.get("required") is not False:
        problems.append(f"{label}: ANTHROPIC_API_KEY must be required: false, got {decl.get('required')!r}")

run_step = None
for job_name, job in (wf.get("jobs") or {}).items():
    job_rest = {k: v for k, v in job.items() if k != "steps"}
    if KEY_REF in str(job_rest):
        problems.append(f"{job_name}: job-level keys reference {KEY_REF}")
    for step in job.get("steps") or []:
        if job_name == "implement" and step.get("name") == "Run Claude Code":
            run_step = step
            continue
        if KEY_REF in str(step):
            problems.append(f"{job_name}: step '{step.get('name')}' references {KEY_REF}")

if run_step is None:
    problems.append("implement: no step named 'Run Claude Code'")
else:
    with_ = run_step.get("with") or {}
    if str(with_.get("anthropic_api_key", "")).strip() != WANT_KEY:
        problems.append(f"Run Claude Code: anthropic_api_key is {with_.get('anthropic_api_key')!r}, want {WANT_KEY!r}")
    if str(with_.get("claude_code_oauth_token", "")).strip() != WANT_OAUTH:
        problems.append(f"Run Claude Code: claude_code_oauth_token is {with_.get('claude_code_oauth_token')!r}, want {WANT_OAUTH!r}")
    if KEY_REF in str(run_step.get("env") or {}):
        problems.append("Run Claude Code: the key must go through with:, not env:")

print("\n".join(problems))
PY
}

# mutate <kind> — writes broken copies to $T/wf.yml and $T/shim.yml.
mutate() {
  python3 - "$1" "$WF" "$SHIM" "$T/wf.yml" "$T/shim.yml" <<'PY'
import sys, yaml
kind, wf_in, shim_in, wf_out, shim_out = sys.argv[1:6]
wf, shim = yaml.safe_load(open(wf_in)), yaml.safe_load(open(shim_in))
def secrets(doc):
    return doc.get("on", doc.get(True))["workflow_call"]["secrets"]
def step(doc, job, pred):
    return next(s for s in doc["jobs"][job]["steps"] if pred(s))
run = lambda: step(wf, "implement", lambda s: s.get("name") == "Run Claude Code")
if kind == "drop-wf-secret":
    secrets(wf).pop("ANTHROPIC_API_KEY", None)
elif kind == "shim-required-true":
    secrets(shim)["ANTHROPIC_API_KEY"] = {"required": True}
elif kind == "drop-api-key-input":
    run()["with"].pop("anthropic_api_key", None)
elif kind == "unconditional-oauth":
    run()["with"]["claude_code_oauth_token"] = "${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}"
elif kind == "leak-review":
    s = step(wf, "ai_review_ai_merge", lambda s: s.get("name") == "Run agent review")
    s.setdefault("env", {})["ANTHROPIC_API_KEY"] = "${{ secrets.ANTHROPIC_API_KEY }}"
elif kind == "leak-selffix":
    s = step(wf, "ai_review_human_merge", lambda s: "self-fix-loop.sh" in str(s.get("run", "")))
    s.setdefault("env", {})["ANTHROPIC_API_KEY"] = "${{ secrets.ANTHROPIC_API_KEY }}"
elif kind == "leak-job-env":
    wf["jobs"]["implement"].setdefault("env", {})["ANTHROPIC_API_KEY"] = "${{ secrets.ANTHROPIC_API_KEY }}"
else:
    sys.exit(f"unknown mutation {kind}")
yaml.safe_dump(wf, open(wf_out, "w"), sort_keys=False)
yaml.safe_dump(shim, open(shim_out, "w"), sort_keys=False)
PY
}

printf '\n── #540 ANTHROPIC_API_KEY: shipped workflows are clean ──\n'
out="$(check_workflows "$WF" "$SHIM")"
if [[ -z "$out" ]]; then pass "agent-implement.yml + shim satisfy #540"; else fail "agent-implement.yml + shim satisfy #540" "$out"; fi

printf '\n── #540 guard catches each broken copy ──\n'
# kind:expected-substring-in-the-problem-report
for spec in \
  "drop-wf-secret:agent-implement.yml: does not declare" \
  "shim-required-true:claude-implement.yml: ANTHROPIC_API_KEY must be required: false" \
  "drop-api-key-input:anthropic_api_key is" \
  "unconditional-oauth:claude_code_oauth_token is" \
  "leak-review:ai_review_ai_merge: step 'Run agent review'" \
  "leak-selffix:ai_review_human_merge: step 'Self-fix loop" \
  "leak-job-env:implement: job-level keys"; do
  kind="${spec%%:*}"; want="${spec#*:}"
  mutate "$kind"
  got="$(check_workflows "$T/wf.yml" "$T/shim.yml")"
  if [[ "$got" == *"$want"* ]]; then pass "flags $kind"; else fail "flags $kind" "want: $want"$'\n'"got: ${got:-<clean>}"; fi
done

printf '\n%d passed, %d failed\n' "$PASS" "$FAIL"
if [[ "$FAIL" -gt 0 ]]; then printf '  - %s\n' "${FAIL_NAMES[@]}"; exit 1; fi
```

````markdown
#### Optional: bill Claude implement runs to API credit (`ANTHROPIC_API_KEY`)

By default every Claude run — implement, review, self-fix — counts against the
Max subscription's usage limit. If the subscription comes with monthly API
credit, a repo can move its **implement** runs onto that credit by setting an
API key from the Console organization linked to the subscription:

```bash
gh secret set ANTHROPIC_API_KEY -R <owner>/<repo>   # paste, then Ctrl-D
```

- With the secret set, the "Run Claude Code" step authenticates with the API
  key **only**; the OAuth token is not passed to it. Remove the secret to go
  back to the subscription.
- Review and self-fix always stay on `CLAUDE_CODE_OAUTH_TOKEN`, so that secret
  is still required.
- Every Claude implement run in the repo now spends real money. `cost-usd` in
  the run report is then actual spend; track it in the Console.
- Verify after the first run: download the `claude-raw-output` artifact and
  check the `init` object's `apiKeySource` — it names the API key, not the
  OAuth token.
- An invalid key or exhausted credit fails the run, currently classified as
  `bug` rather than as a credit problem. If runs start failing right after the
  key was set, check the Console balance first.
- The stub generated by `scripts/onboard-consumer.sh` already forwards
  `ANTHROPIC_API_KEY`. It needs a pipeline release that declares the secret
  (the release containing #540); pin `pipeline-ref` / `@v2` to that release or
  newer. Hand-written stubs without `secrets: inherit` must add
  `ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}` to the `secrets:` block.
````
